# RankMaker 수동 테스트 시나리오

1. `node tests/unit.mjs` 통과 확인
2. `index.html` 을 Chrome / Edge 로 열고 `topics` 연결, F12 콘솔 열어두기
3. 아래를 위에서부터 수행. 고친 뒤 시간이 없으면 **A · C · F · G · J** 만

## 준비물 `topics/ex_image_source/`

| 항목 (표시 순) | 그림 위치 |
|---|---|
| 1 그림 있음.png | `topics/images/` |
| 2 그림 있음.png | `topics/images/` |
| 3 그림 있음.png | `topics/images/` |
| 4 그림 없음.svg | 없음 |
| 5 주소 CORS 미허용.jpg | 주소만 — BGG |
| 6 주소 CORS 허용.png | 주소만 — raw.githubusercontent |

되돌리기:

```
rm -f "topics/images/5 주소 CORS 미허용.jpg" \
      "topics/images/6 주소 CORS 허용.png" \
      "topics/ex_image_source/save.json"
```

## B'. 검색

`ex_image_boardgame` 에서 확인한다. `Elwen` 은 설명(디자이너)에만 있고 아이템명에는 없다.

| # | 조작 | 기대 |
|---|---|---|
| S1 | 검색창을 본다 | placeholder 가 `Search (초성 지원)`, 옆에 `Details` 체크박스 |
| S2 | `아르낙` 입력 | 아르낙 항목 2개만 남는다 |
| S3 | 초성 `ㅇㄹㄴ` 입력 | 같은 2개가 남는다 |
| S4 | `Elwen` 입력 | **아무것도 안 나온다** (설명에만 있으므로) |
| S5 | 그 상태로 `Details` 체크 | 아르낙 2개가 나타난다 |
| S6 | 체크한 채 초성 `ㄷㅈㅇㄴ` 입력 | 설명의 `디자이너` 에 걸려 항목이 나온다 |
| S7 | 체크를 풀고 같은 초성 | 아무것도 안 나온다 |
| S8 | 체크한 채 새로고침 | 체크가 풀려 있다 (저장하지 않는다) |
| S9 | 창을 좁게 (≤560px) | 체크박스만 남고 글자는 사라진다 (마우스 올리면 설명) |
| S10 | `아르낙` 입력 | 아이템명의 `아르낙` 부분에 **하이라이트**가 칠해진다 |
| S11 | 초성 `ㅇㄹㄴ` 입력 | 이름의 `아르낙` **세 글자에만** 칠해진다 (초성 자리와 어긋나지 않는다) |
| S12 | `Details` 체크 + `Elwen` (List 보기) | 설명의 `Elwen` 에 칠해진다 |
| S13 | 체크를 풀고 같은 검색어 | 설명에는 칠해지지 않는다 |
| S14 | 설명에 링크가 있는 항목에서 링크 일부를 검색 | 링크는 링크 그대로 — 하이라이트로 깨지지 않는다 |
| S15 | 라이트/다크를 번갈아 전환 | 양쪽 모두 글자가 또렷하게 읽힌다 |

## F. 포스터 저장 안내 ★

되돌리기 후 시작.

| # | 조작 | 기대 |
|---|---|---|
| F1 | `ex_image_source` 를 연 직후 **Podium → Poster (Insta)** | 안내창 없이 바로 저장된다 |
| F2 | 이어서 **Poster — Top 10** | 안내창이 뜬다 |
| F3 | **5 주소 CORS 미허용** 을 1위로 드래그 후 **Poster (Insta)** | 저장되지 않고 안내창이 뜬다 |
| F4 | 안내창 내용 | `topics/images/` 경로, 파일명, **[이미지 열기]** 가 보인다 |
| F5 | **[이미지 열기]** 클릭 | 새 탭에 그림이 열린다 |
| F6 | 우클릭 저장 → `topics/images/5 주소 CORS 미허용.jpg` → 다시 **Poster (Insta)** | `이미지 1개를 읽었습니다 ✓` 후 포스터가 저장된다 |
| F7 | F6 의 결과 이미지 | 그 자리가 이름 카드가 아니라 실제 그림이다 |
| F8 | 되돌리기 후 F3 반복 → **이름 카드로 그냥 저장** | 안내창이 닫히고 포스터가 저장된다 |
| F9 | 같은 상태에서 **닫기** 또는 `Esc` | 아무것도 저장되지 않는다 |
| F10 | 읽기 전용(A4)에서 F3 | 안내창에 읽기 전용 문단이 함께 보인다 |

## J. Undo ★

Tier · List · Gallery 모두. `Ctrl+Z`(맥 `Cmd+Z`)도 동일.

| # | 조작 | 기대 |
|---|---|---|
| J1 | 주제를 연 직후 | Undo 버튼이 흐리게 비활성 |
| J2 | 드래그로 옮긴다 | 버튼 활성. 툴팁에 남은 단계 수 |
| J3 | Undo 클릭 | 직전 상태로 돌아가고 `Undone ✓` 가 뜬다 |
| J4 | 세 번 옮기고 Undo 세 번 | 역순으로 풀리고 마지막에 비활성 |
| J5 | 티어 간 이동 후 Undo | 위치와 티어 크기가 함께 돌아온다 |
| J6 | **+ Add Tier** 후 Undo | 추가된 티어가 사라진다 |
| J7 | 티어 **×** 후 Undo | 티어와 항목 배치가 되살아난다 |
| J8 | 티어 이름 변경 후 Undo | 이전 이름으로 돌아간다 |
| J9 | 티어 이름 칸을 열었다 그대로 빠져나오기 | 단계가 쌓이지 않는다 |
| J10 | 체크박스를 켜고 Undo | 체크가 풀린다 |
| J11 | 순위 입력칸으로 이동 후 Undo | 원래 자리로 돌아간다 |
| J12 | 맨 위 항목을 위로 더 올리기 | 아무 일도 없고 단계도 안 쌓인다 |
| J13 | 메모칸 입력 중 `Ctrl+Z` | 메모 글자만 되돌아간다 |
| J14 | 검색창에 커서를 둔 채 `Ctrl+Z` | 검색어만 되돌아간다 |
| J15 | Undo 여러 번 후 새로고침 | 되돌린 결과가 저장돼 있다 |
| J16 | 주제를 바꿨다 돌아오기 | 버튼이 비활성 |
| J17 | 50번 넘게 옮긴 뒤 Undo 반복 | 50단계까지만 풀린다 |
