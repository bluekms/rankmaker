# RankMaker 수동 테스트 시나리오

1. `node tests/unit.mjs` 통과 확인
2. `index.html` 을 Chrome / Edge 로 열고 `topics` 연결, F12 콘솔 열어두기
3. **아래 빠른 점검 10건**만 돌린다. 그 구간을 고쳤을 때만 해당 상세 절로 내려간다
4. 끝나면 `node tests/reset.mjs --yes`

---

## ⚡ 빠른 점검 — 10건

`ex_image_source` 를 열고 위에서부터. 각 줄 끝의 표시는 깨졌을 때 볼 상세 절이다.

| # | 조작 | 기대 | 상세 |
|---|---|---|---|
| Q1 | 주제를 연다 | 1·2·3 번이 그림, 4번은 이름 카드, 5번은 BGG 그림. 잠시 뒤 `Saved ✓ · 1 image(s)` | C · D · E |
| Q2 | 항목을 드래그해 티어로 옮긴다 | 옮겨지고 `Saved ✓` | B |
| Q3 | **↶ Undo** | 제자리로 돌아가고 `Undone ✓` | J |
| Q4 | 검색창에 `그림` 입력 | 해당 항목만 남고 이름에 하이라이트 | B' |
| Q5 | `All Text` 체크 | 설명에 `그림` 이 있는 항목까지 늘어난다 | B' |
| Q6 | **5 주소 CORS 미허용** 을 1위로 올리고 **Podium → Poster (Insta)** | 저장 안 되고 안내창이 뜬다 | F |
| Q7 | `[Open image]` → 우클릭 이미지 복사 → **`Paste → …`** | 안내창이 닫히고 포스터가 저장된다 | F |
| Q8 | Q7 의 포스터 이미지 | 그 자리가 이름 카드가 아니라 실제 그림 | F |
| Q9 | 월드컵을 돌려 우승자 화면에서 **Save Image** | 포스터가 저장된다. 우승자 화면 그대로 | G |
| Q10 | 창을 1300px 근처까지 좁힌다 | 검색창만 줄고 좌우 버튼은 그대로 | K |

> 이 10건이 **공용 이미지 폴더 · 주소 표시 · 자동 내려받기 · 검색 · 되돌리기 · 포스터 안내 · 붙여넣기 · 월드컵 유지 · 반응형** 을 한 번씩 지나간다.
> 하나라도 어긋나면 그 줄의 **상세** 절만 펼쳐 원인을 좁힌다.

```

node tests/reset.mjs --yes    실행
```

## K. 상단바 레이아웃

```
[Topic ▼][Save][Load] Saved ✓ ··· [↶ Undo][ Search ][☐ All Text] ··· [Tier|List|Gallery][Size/Cols][Podium] │ [🏆 WorldCup][🌙]
```

| # | 조작 | 기대 |
|---|---|---|
| K1 | 넓은 창(1400px 이상)에서 상단바 | 세 묶음이 왼쪽·정가운데·오른쪽에 놓인다 |
| K2 | Topic 이름이 아주 긴 주제를 고른다 | 가운데 묶음이 **여전히 정가운데**다 (좌우 폭에 안 흔들린다) |

| K4 | `Podium` 과 `WorldCup` 사이 | 세로 구분선이 보인다 |
