# 그림을 주소로 붙이기 (심화)

> [한국어](image-url.md) | [English](image-url.en.md) · [← README](../README.md)

보통은 그림 파일을 `topics/images/` 에 넣으면 끝입니다. **이 문서는 그렇게 하기 곤란한 경우**를 위한 것입니다.

- 항목이 수백 개라 그림을 다 받아 두면 폴더가 너무 무거울 때
- 그림이 이미 웹에 있고, 그걸 그대로 쓰고 싶을 때

## 쓰는 법

항목 설명에 그림 주소를 한 줄 적으면 됩니다. `🖼` 는 눈에 띄라고 붙인 장식일 뿐, 문법이 아닙니다.

```markdown
# 오를레앙.jpg
- ⭐ bgg 점수: 8.05
+ 🖼 https://example.com/images/orleans.jpg
```

- 같은 이름의 **파일이 있으면 파일이 이깁니다.** 주소는 파일이 없을 때만 쓰입니다.
- 주소는 **항목당 하나**면 충분합니다. 여러 개 적으면 첫 번째만 쓰입니다.
- 확장자가 `jpg` `png` `webp` `gif` `avif` 이거나 알려진 썸네일 호스트여야 그림으로 인식됩니다.
- 인식된 주소 줄은 **설명에 보이지 않습니다.** 그림으로 쓰였으니 글로 또 보여줄 이유가 없습니다.

## 화면에는 잘 보이는데 포스터에는 안 들어갑니다

주소로 붙인 그림은 순위표에서 멀쩡히 보입니다. 그런데 **Podium** 으로 포스터를 뽑으려 하면 안내창이 뜹니다.

```
The poster needs these images as files
Download each one into topics/images/ under the same filename, then save again.
```

브라우저 보안 규칙 때문입니다. 포스터는 캔버스에 그림을 그려 PNG 로 뽑는데, 다른 사이트의 그림을 캔버스에 그리면 그 캔버스가 **오염된 것으로 표시되어** 내보내기가 막힙니다. 남의 이미지 픽셀을 몰래 읽어 가는 것을 막으려는 규칙이라 우회할 방법이 없습니다.

그림이 있는 서버가 `Access-Control-Allow-Origin` 헤더로 사용을 허락하면 이 문제가 없습니다. 다만 그런 서버는 많지 않습니다.

### 안내창에서 하는 일

| | |
|---|---|
| **Paste** | 그림을 우클릭해 **이미지 복사** 한 뒤 누르면, 앱이 **항목 이름 그대로** `topics/images/` 에 저장합니다. 폴더를 찾아가거나 파일명을 맞출 필요가 없습니다. 여러 개면 하나씩 반복하면 되고, 마지막을 채우면 안내창이 닫히며 포스터가 저장됩니다 |
| **Open image ↗** | 그림을 새 탭에 엽니다. 직접 내려받아 넣고 싶을 때 씁니다 |
| **Save with name cards** | 그냥 진행합니다. 그 자리는 이름만 적힌 카드로 들어갑니다 |

한 번 받아 두면 그 뒤로는 평범한 로컬 파일이라 다시 물어보지 않습니다. 공용 폴더라 **다른 주제에서도 그대로 쓰입니다.**

### 자동으로 받아지는 경우도 있습니다

그림 서버가 사용을 허락하는 곳(`Access-Control-Allow-Origin: *`)이면, 주제를 열 때 앱이 **알아서 받아 저장**합니다. `Saved ✓ · 1 image(s)` 가 뜨면 그런 경우입니다. 이때는 안내창이 아예 뜨지 않습니다.

`info.md` 의 주소를 나중에 다른 그림으로 바꾸면, 그것도 알아서 다시 받습니다.

## 정리

| 무엇을 하려는가 | 권하는 방법 |
|---|---|
| 순위를 매기고 **포스터를 뽑겠다** | 그림 파일을 `topics/images/` 에 넣기 |
| 수백 개짜리 **목록만 만들겠다** | 주소로 붙이기 |
| 섞고 싶다 | 섞어도 됩니다. 파일이 있는 항목은 파일을, 없는 항목은 주소를 씁니다 |
